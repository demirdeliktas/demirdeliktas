# Önce / Sonra

- `post.html` → `post.png`: 1080×1350 Instagram postu (sol ÖNCE, sağ SONRA). `node render.js` ile yeniden üretilir.
- `slider.html`: portföy sitesi için sürüklenebilir karşılaştırma bileşeni. Fare, parmak (mobilde yatay sürükleme; dikey kaydırma sayfayı kaydırır) ve klavye (Tab + ok tuşları) ile çalışır. Bağımlılık yok; `once.jpg` ve `sonra.jpg` ile aynı klasörde durmalı.
  - Birden fazla karşılaştırma için `.ba` bloğunu kopyalayıp görselleri değiştirin.
  - `data-start` başlangıç konumunu, `--before-pos` / `--after-pos` görsellerin kırpma odağını ayarlar.
- `sonra.jpg` yapay zekâ (Higgsfield) ile üretilmiştir. Ürün: saksıda Pilea (para ağacı).
